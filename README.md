# StudyVision

StudyVision is a real-time computer-vision prototype that estimates an
**observed study activity** from webcam-derived eye features. It recognizes
four study-mode labels:

- `paper_study`
- `screen_study`
- `typing_study`
- `mixed_study`

The system uses MediaPipe Face Mesh to obtain face landmarks, extracts
eye-aspect-ratio (EAR) measurements, derives temporal features, and applies a
200-tree Random Forest classifier. The live application collects a 30-frame
window before predicting and applies majority smoothing across the five most
recent predictions to reduce flicker.

## Project pipeline

```text
Webcam -> face landmarks -> EAR and temporal features -> Random Forest
       -> 30-frame activity window -> 5-prediction smoothing -> display
```

## Dataset

- 48,267 raw samples collected across 18 sessions
- 48,111 cleaned samples retained after data-quality filtering
- Four activity labels: paper, screen, typing, and mixed study
- Feature dataset: `data/studyvision_features.csv`

The raw and cleaned data are preserved in `data/`; they are not regenerated by
the normal live-prediction command.

## Evaluation summary

Evaluation uses leave-one-session-out testing, which keeps every sample from
the tested recording session out of training.

| Metric | Result |
|---|---:|
| Frame-level mean session accuracy | 0.4977 |
| Frame-level sample-weighted accuracy | 0.4826 |
| 30-sample-window mean session accuracy | 0.5451 |
| 30-sample-window weighted accuracy | 0.5223 |
| Held-out `validation_001` window accuracy | 0.8214 |
| Held-out `validation_002` window accuracy | 0.7143 |

Detailed per-session results are in `docs/evaluation_results.md`.

## Run the project

From the project root, create and activate a Python 3.11 virtual environment,
then install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run the saved-model live prototype:

```bash
PYTHONPATH=src python src/studyvision/predict.py
```

The webcam window begins predicting after it has collected 30 face-detected
frames. Press `q` in that window to finish the session. Each live run saves
one-second observations to `data/session_logs/` and creates a local HTML
summary dashboard in `reports/`.

During a live session, press `b` to start a manual break and press `b` again
to resume studying. Manual breaks are counted separately from distractions;
press `q` at any time to finish the whole session.

To reproduce the window-level evaluation:

```bash
PYTHONPATH=src python src/studyvision/evaluate_windows.py
```

## Important limitation

StudyVision classifies **observable activity patterns**, not a person's
internal attention, motivation, or learning quality. Its current five features
are all eye-derived, so the system is most useful as a prototype and can
confuse activities with similar eye behavior (for example, typing, screen
study, or brief non-study actions). The documented session-level evaluation is
the appropriate estimate of current generalization performance.

For live-session summaries, the interface only shows **Studying** and
**Distracted**. A distraction is recorded after the face has been continuously
absent from the webcam for three seconds. The dashboard reports observed study
time, manual-break time, distracted time, and the number of separate break and
distraction episodes. This
is deliberately an observable proxy rather than a claim to infer a student's
mental state without a labeled distraction dataset.
